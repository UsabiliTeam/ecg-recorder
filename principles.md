Guiding principles

1. Speed: The application should feel lighting fast to users. 
2. Reliability: Prevent errors, test everything, and never lose user data.
3. Security: Assume attackers exist, who would find loop holes. Play as ethical hacker and find all vulnerabilities.
4. Flexibility: The app will have nuanced feature addition. The codebase should be flexible to support rapid updation.
5. Design: Keep the design clean and calm, and remove anything that is not needed. But some fun subtle text copies here and there would be nice.
6. Features: Make features work instantly for beginners, and give experts shortcuts and more power.
7. Copy: Write short, clear, friendly text that never lectures the user.
8. Fun: Add small moments of delight wherever you can. But keep the quality bar very high.
9. Accessibility: Make sure everyone, including people using keyboards or screen readers, can use the app. But also ensure it doesn't make app cumbersome for regular users.
10. Testing should be extremely efficient. Do smaller tests with a short time window first, then larger and larger tests.
11. In our conversations, be super crisp, to the point. No long elicitation. What has been done, what questions do you have, (in priority order), and anything else that is critical. Super short.
12. Acknowledge and accept when you do a mistake.
13. Progress reporting: For long tasks, make a numbered plan and report progress like "3/6" after each finished step.
14. Code quality: Write clean, readable code with no unnecessary complexity. Document only the non-obvious: hidden constraints, invariants, and the "why" behind a tricky decision — not what the code already says.
